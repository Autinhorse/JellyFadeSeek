# 原型代码说明

## 运行

`npm install` 后 `npm run build`，打开 `dist/index.html`。开始界面有两个模式：“当躲藏方”和“当猎人（看 AI 躲）”。右下角常驻显示帧数。

`prototype/` 下是交接时构建好的两个页面，可以直接双击打开：`game.html` 是游戏，`slice.html` 是最初的客厅画面样板。

## 文件

模拟部分（不依赖渲染，Node 里能直接跑）：

| 文件 | 负责 |
|---|---|
| `src/config.js` | 全部可调数值 `CONFIG`，以及调试面板条目 `DEBUG_ITEMS` |
| `src/world.js` | 地图。40×30 米，房子占 x 6..34、z 3..18，后院 z 18..30。产出碰撞盒 `W.boxes`、渲染用的基础零件 `W.parts`、高层道具 `W.props`、房间、巡逻点、可翻越的矮窗 `W.steps` 等 |
| `src/sim.js` | `class Game`：可见度、发现值、视线检测（线段对长方体）、网格寻路 `Nav`（0.25 米格子）、猎人状态机、颜料弹、防挂机、计分、AI 躲藏方。通过 `events` 队列把发生的事告诉外层 |

渲染和界面：

## 画面管线要点

- Three.js r0.187。`MeshStandardMaterial` / `MeshPhysicalMaterial`，程序贴图，天空生成的 PMREM 环境贴图。
- `NeutralToneMapping`，曝光 1.12。阴影贴图 4096，`PCFShadowMap`。
- 后期：`RenderPass → GTAOPass → UnrealBloomPass → OutputPass → SMAAPass`，半浮点渲染目标，4 倍采样。
- 果冻用 `transmission`（真实折射）加 `iridescence`。
- 绿篱材质用 `onBeforeCompile` 按世界坐标算波浪花纹，不依赖 UV。

## 踩过的坑

改相关代码前先看一遍，免得重犯。

- **光柱变黑**：GTAO 会把半透明光柱当成实心物体。现在通过给 `gtao._overrideVisibility/_restoreVisibility` 打补丁，把这类物体排除在环境光遮蔽之外。
- **小窗里看不到果冻**：`transmission` 材质在裁剪视口里直接渲染会失效。现在先渲染到 512 的渲染目标，再贴到屏幕上。
- **天空出现黑色多边形**：相机远裁剪面小于天空球。相机 `far` 现在是 450。
- **地面闪烁**：地板和地面重叠。地板抬高到 0.006 / 0.016。
- **屋顶是倒的**：两片屋顶的倾斜方向（`rx` 符号）容易写反，会变成 V 形并穿进天花板。
- **蹲姿露头**：蹲姿身高原来 1.05，比 1 米的矮掩体高。现在 0.9，矮掩体不低于 1.0。
- **半透明没用**：发现值最初和可见度成正比，6 米外静止 2 秒就被发现。加了 `visPower: 2`。
- **床底必胜**：趴在床底不动原来稳赢。现在防挂机提示会逐步变准，猎人到达后会弯腰查看、对趴着的目标压低瞄准。
- **猎人弯腰穿地板**：弯腰动作不能整体下移，现在是压扁加前倾。
- **寻路**：起点和终点在同一格且该格被挡时，`Nav.path` 要返回空路径。巡逻点不能放在家具里或被门口的杂物挡住。
- **鼠标锁定**：只能在点击事件里请求。有的环境锁不上，所以保留了拖动和 Q/E 转向。

## 已知的粗糙之处

- 一些杂物还是简单几何体，没有重做：帐篷、玩具、钢琴、自行车、洗衣机、上铺、遮阳伞、蹦床、狗屋、沙坑、秋千、垃圾桶、柴堆、信箱、石板路。
- 第一人称视角里的喷枪模型比较简陋。
- 左下角小窗没有经过后期处理，颜色比主画面淡一点。
- 猎人头顶的“?”“!”标记会透过墙显示。
- 动画流畅度和音效只在负责人机器上粗看过，没有系统检查。
- 数值只针对 AI 调过，没有真人对局数据。
